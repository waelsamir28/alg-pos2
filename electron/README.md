# تشغيل نسخة سطح المكتب (Electron) — نسخة تجريبية

نسخة سطح المكتب تشغّل نفس ملفات الويب داخل نافذة Electron، مع قاعدة بيانات محلية على الجهاز
نفسها المستخدمة في المتصفح (`localStorage`).

## المتطلبات

- Node.js 22 أو أحدث
- أول مرة فقط: `npm install` (يُنزّل Electron، ويحتاج إنترنت)

## التشغيل أثناء التطوير

```bash
npm run dev            # خادم التطوير على http://127.0.0.1:3000
npm run electron:dev   # نافذة Electron تعرض خادم التطوير (تحديث فوري) — يعمل على ويندوز أيضًا
```

أو تشغيل النافذة مستقلة عن خادم التطوير (الطريقة التي تعمل في النسخة المثبّتة):

```bash
npm run electron       # يشغّل خادم داخلي على 127.0.0.1:41730 ثم يفتح النافذة
```

## بناء ملف EXE لويندوز

```bash
npm run dist:dir       # نسخة غير مثبّتة داخل dist-electron/win-unpacked (أسرع تجربة)
npm run dist           # مثبّت NSIS + نسخة portable داخل dist-electron/
```

النواتج:

- `dist-electron/ALG POS Setup <version>.exe` — مثبّت (اختيار مسار التثبيت + اختصار على سطح المكتب)
- `dist-electron/ALG-POS-<version>-portable.exe` — نسخة تعمل بدون تثبيت

> البناء يجب أن يُنفَّذ على ويندوز أو مع Wine؛ ملفات Electron الثنائية تُنزَّل من الإنترنت وقت البناء.
> مجلد `dist-electron/` مستبعد من Git.

## كيف يعمل

- `main.js` هو نقطة الدخول: يفتح نافذة واحدة بمقاس 1440×900 بحد أدنى 1024×680، بدون شريط قوائم،
  ويمنع النوافذ الإضافية (أي رابط خارجي يُفتح في المتصفح الافتراضي).
- `electron/local-server.js` يقدّم حزمة التطبيق (`index.html`, `app.js`, `lib/`, `fonts/`, الأيقونات)
  على `http://127.0.0.1:<port>` — وهذا ضروري لأن مسارات التطبيق مطلقة (`/app.js`) وتخزين
  `localStorage` يجب أن يبقى على أصل ثابت بين التشغيلات.
- لا يُقدَّم أي ملف آخر: `package.json` و`api/` و`tests/` و`node_modules/` غير متاحة عبر الخادم،
  ولا يوجد Node داخل الصفحة (`nodeIntegration: false`, `sandbox: true`, `contextIsolation: true`).
- `/api/sync` يمر على نفس معالج المزامنة في `api/sync.js`، ويعمل فقط عند توفّر
  `DATABASE_URL` و`SYNC_TOKEN` في بيئة التشغيل؛ وبدونها يعمل البرنامج محليًا بالكامل وتظهر رسالة
  أن المزامنة السحابية غير مهيّأة.
- نسخة واحدة فقط تعمل في نفس الوقت (`requestSingleInstanceLock`) حتى تبقى قاعدة البيانات المحلية واحدة.

## إعدادات إضافية عبر متغيرات البيئة

| المتغير | الوظيفة |
|---|---|
| `POS_FULLSCREEN=1` | تفتح النافذة على كامل الشاشة |
| `POS_KIOSK=1` | شاشة كاشير مقفلة (بدون تصغير/تكبير/شريط نظام) |
| `POS_ZOOM=0.9` أو `1.15` | تصغير/تكبير واجهة البرنامج كاملة |
| `POS_USER_DATA=1` | وضع قاعدة البيانات في مجلد فرعي قابل للنسخ الاحتياطي بسهولة |

## ملاحظات للنسخة التجريبية

- التثبيت غير موقّع رقميًا، لذا سيظهر تحذير Windows SmartScreen عند أول تشغيل
  (More info ← Run anyway).
- تحديث التطبيق يدوي: إعادة البناء والتثبيت فوق النسخة القديمة. بيانات `localStorage` تبقى لأن
  مسار بيانات Electron (`%APPDATA%/ALG POS`) لا يتغيّر.
